# Artifact Library

A private claude.ai page that holds links to all of Clifton's Claude dashboards and artifacts.

- Open: https://claude.ai/artifact/53JnMS56PgSQmNvCXPrhzn (owner only unless shared)
- Group by area, pin, search, archive, add new links.
- To add a new artifact: use **Add artifact** on the page, or ask Claude "add it to my library".

The artifact list itself is stored in the page's database, not in this repo.
