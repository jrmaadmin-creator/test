# docs/

Diataxis: one purpose per file.
- `how-to/`: steps for a specific task (add a call, update for new protocols).
- `reference/`: facts to look up (every call, its NH sections, review status).
- `explanation/`: why the game is built this way (learning design, evidence).
- `adr/`: architecture decisions. Numbered, never rewritten; supersede with a new ADR.

Plain language. Tables for anything scanned. No em dashes.
