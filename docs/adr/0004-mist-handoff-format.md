# ADR 0004: MIST handoff report

Status: Accepted · 2026-09-29

**Context.** Bedside handoff to an ED RN must be short. Options: MIST, SBAR, SOAP.

**Decision.** MIST (Medical complaint, Illness/findings, Signs, Treatment) plus field impression, red flags, SAMPLE highlights, and a full timeline below.

**Consequences.**
- + Built from data already tapped in; no extra typing.
- + Copy button gives text for the ePCR narrative.
- − Receiving facilities that expect SBAR get a different order; add an SBAR view if needed.
