# How to set up the pre-arrival fax to MCH

1. **Ask MCH ED** (nurse manager): Do you want a pre-arrival sheet? Which fax number is watched in real time? Who checks it?
2. **Pick a fax service that signs a BAA** and supports email-to-fax (examples to compare: Documo mFax, SRFax, eFax Corporate). Sign the BAA.
3. **JRMA Google Workspace:** an admin accepts Google's HIPAA BAA in the Admin console (Account → Legal and compliance). Send only from JRMA accounts.
4. In the fax service, allow JRMA sending addresses and note the email-to-fax address for the MCH ED number (format is vendor-specific).
5. **In the app:** To ED tab → Settings → enter unit name, crew callback number, and the email-to-fax address.
6. **Test** with a dummy call on a quiet shift and confirm MCH received a legible page and you got the delivery receipt.

On a call: To ED tab → ETA → alerts → **Email to fax** → tap Send in the mail app. Always give the radio/phone report too.
