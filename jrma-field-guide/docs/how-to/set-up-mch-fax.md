# How to set up the pre-arrival fax

1. **Ask the receiving ED** (nurse manager): do you want a pre-arrival sheet, and which fax number is watched in real time?
2. **Sign up for SRFax Healthcare** (srfax.com, Healthcare Lite plan) using a JRMA role mailbox. Request and sign the BAA.
3. **Register the sending email address(es)** in SRFax. SRFax only accepts email-to-fax from registered senders.
4. **JRMA Google Workspace:** an admin accepts Google's HIPAA BAA in the Admin console (Account → Legal and compliance).
5. **In the app:** To ED tab → Settings → Fax service **SRFax** → destination fax number. The app shows the address it will use (`1` + number + `@srfax.com`).
6. **Test:** tick **Test mode**, run a practice call, tap **Email to fax**, send from the registered address. Station fax 603-532-2405 is the test destination. Confirm the page prints and the delivery receipt arrives.
7. Untick Test mode and change the number to the ED's fax.

On a call: To ED tab → ETA → alerts → **Email to fax** → tap Send in the mail app. Always give the radio/phone report too.
