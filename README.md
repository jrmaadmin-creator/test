# EMT Call Guide

Offline phone app for NH EMT-B patient care: step-by-step protocol flow, questions to ask, time-stamped interventions and vitals, field-impression prompts, and a MIST handoff report for the receiving RN.

**Status: all protocol content is UNVERIFIED.** The NH Patient Care Protocols v9.2 text is not yet loaded. Follow the official protocols. See `docs/how-to/verify-a-protocol.md`.

```bash
npm test            # 10 tests, no dependencies
npm run validate    # protocol graph check
npm run serve       # http://localhost:8080
```
