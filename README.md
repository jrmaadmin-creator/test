# Personal space

Type: reference (map). Status: v0.1, 2026-09-29. Owner: you.

Your personal projects on GitHub. JRMA work lives in `jrma-ops`, never here. Both sit in the `jrmaadmin-creator` account until you create a personal GitHub account (`adr-002-one-github-account-for-now.md`). Then this repo moves with one transfer (`how-to-move-personal-repos-to-a-personal-account.md`).

Before anything personal goes in:

1. Make this repo private: Settings > General > Danger Zone > Change visibility. It is public today.
2. Rename it: Settings > General > Repository name. Suggestion: `personal`.
